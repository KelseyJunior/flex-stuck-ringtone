How this page works

The audio player is Flex's own code, taken unchanged from the installed @twilio/flex-ui package, and the sound is your browser's. Only TaskRouter is simulated: the buttons play its part ("a reservation arrives", "the agent goes Offline, so pending reservations are rejected"). The server delays the ringtone file to stand for a slow network.

  • Silent: nothing playing.
  • Ringing: a reservation is pending. This is normal.
  • Stuck: ringing with no pending reservation. This is the bug.

What to expect:

Reproduce

  1. Two reservations arrive while the agent is Available.
  2. The agent goes Offline before the ringtone has loaded.
  3. Without the fix: "Error playing media." shows, then the ringtone loops forever.
